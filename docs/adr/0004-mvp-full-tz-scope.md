# MVP scope is the full ТЗ

The MVP is scoped to the full ТЗ: the entire §53 chain (RSS → extraction → dedup → clustering → facts → importance → translation → terminology → editorial → quality → content → Card PNG) plus the AI-text detector (§17) and local LLM fallback (§19) that the ТЗ assigns to MVP-2, all outputs (Story JSON, Card PNG, Telegram, VK carousel, horizontal video), a golden dataset of 100+ real gaming news (§45), a full benchmark framework (§42), and Docker Compose (§52). All OSS components are real from day one (Miniflux, Trafilatura, Natasha, OPUS-MT, SearXNG, imagehash, CLIP/SigLIP) — no mocks or stubs. Build order: core → image pipeline → outputs → benchmark. This collapses the ТЗ's MVP/MVP-2/MVP-3 phasing into a single ambitious MVP; the trade-off is a large build, mitigated by ticket-based execution in dependency order.
